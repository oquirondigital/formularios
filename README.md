# Formulários · Oquíron Digital

Páginas de formulário de qualificação para as campanhas da Oquíron, uma pasta por nicho.
Publicado via GitHub Pages em **form.oquirondigital.com.br**.

| Pasta | Endereço | Nicho |
|---|---|---|
| `lojas-iphone/` | form.oquirondigital.com.br/lojas-iphone | Donos de loja de iPhone/celular |

Cada página tem um bloco `CONFIG` no começo do script (webhook do n8n que grava no CRM, Pixel, WhatsApp, cases e resultados).
A raiz redireciona para o site da Oquíron.
